# Rx Jobs

A personal Android app listing Assistant / Associate Professor, Professor and Scientist openings in Pharmaceutical Sciences across India, matched to a B.Pharm + M.Pharm (Pharmaceutics) + Ph.D. profile.

**Download the app:** [RxJobs.apk](https://github.com/officialcricketbanter-hub/rx-jobs-app/releases/download/latest/RxJobs.apk)

- `www/` — the app
- `data/jobs.json` — the job feed, refreshed every morning by a scheduled search
- `.github/workflows/build-apk.yml` — builds the APK on every app change
